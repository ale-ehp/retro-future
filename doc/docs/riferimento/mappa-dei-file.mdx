# Mappa dei file

La demo è `index.html` più la cartella `src/`, servita senza bundler: 97 moduli
JavaScript, 35 file di prova accanto ai moduli che provano, un file di dichiarazioni
(`globali.d.ts`) e la libreria three.js copiata in `vendor/`. Le righe sono contate il
20 settembre 2026; cambiano a ogni commit, e questa pagina non insegue il numero
esatto ma la forma: quali cartelle esistono, cosa ci sta dentro, quanto pesa ognuna.

Le cartelle:

| cartella | cosa tiene |
|---|---|
| `src/` (radice) | `main.js`, che apre i sottosistemi nell'ordine giusto e li lega; `ctx.js`; `lingua.js`; le prove trasversali (invarianti, ordine di boot e frame, importmap, scorciatoie di console) |
| `src/engine/` | post-processing, ciclo dei fotogrammi, prewarm, diagnostica, benchmark, shader, ispezione |
| `src/world/` | boulevard, palazzi, ponti, LED, tabelloni, pavimento a esagoni, cielo, rivelo, terminale |
| `src/character/` | modelli, animazione, folla, percorsi, chi accoglie, fumetti, passi, riflessi |
| `src/camera/` | stato del giocatore, mouse look, volo del drone, cursore, collisioni della camera |
| `src/controls/` | pannello di regia, controlli dal vivo, tastiera, movimento, mobile, copertina |
| `src/audio/` | contesto audio, colonna sonora, passi |
| `src/config/` | costanti pure |
